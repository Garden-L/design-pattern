# 02 Bridge

이 디렉터리는 02 Bridge 패턴의 강의용 실행 코드를 담습니다.

## 읽는 순서

1. 직접 구현 — examples/01_direct.rs에서 패턴 없이 요구사항을 해결합니다.
2. 설계 적용 — examples/02_*.rs에서 변경 지점을 분리하고 패턴을 적용합니다.
3. 테스트 확인 — 챕터의 tests/에서 같은 계약이 유지되는지 확인합니다.
4. 직접 연습 — exercise/02-structural/02-bridge/의 TODO를 구현합니다.

두 파일의 목적은 버전 비교가 아니라, 문제의 변화와 설계 선택을 설명하는 것입니다. 구현을 읽을 때는 왜 이 추상화가 필요한가, Rust의 enum·trait·소유권이 어떤 역할을 하는가, 패턴 없이도 충분한 조건은 무엇인가를 함께 기록하세요.

## 실행

cargo test -p bridge
