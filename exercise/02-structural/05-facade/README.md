# 05 Facade 연습

강의 코드 chapters/02-structural/05-facade/를 먼저 읽고, 이 패키지에서 같은 문제를 직접 구현합니다.

## 학습 순서

1. 강의의 examples/01_direct.rs에서 요구사항과 직접 구현을 확인합니다.
2. examples/02_*.rs에서 설계 적용 결과를 비교합니다.
3. 이 디렉터리의 src/lib.rs에 직접 구현합니다.
4. tests/exercise.rs에 자신의 요구사항 테스트를 추가합니다.

## 실행

cargo test -p exercise-02_structural-05_facade

src/lib.rs는 의도적으로 비어 있는 연습용 시작점입니다.
