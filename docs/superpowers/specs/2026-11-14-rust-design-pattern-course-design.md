# 러스트로 배우는 디자인 패턴 강의/책 설계

## 의도와 배경

러스트 입문자부터 고급자까지 디자인 패턴을 단계적으로 학습할 수 있는 책자형 강의를 만든다. GoF 패턴을 기준으로 생성·구조·행동 패턴을 다루고, 러스트의 소유권·트레잇·열거형·제네릭·동시성·비동기 설계가 패턴을 어떻게 바꾸는지 설명한다. 노션은 독학/강의용 책자와 서브 페이지를 제공하고, 로컬 저장소는 챕터별 실행 가능한 러스트 코드와 테스트를 보관한다.

## 목표

- 입문·중급·고급 학습 경로를 하나의 연속된 과정으로 제공한다.
- 모든 핵심 패턴을 적용 전/적용 후 코드로 비교한다.
- 각 챕터가 설명, 리팩터링, 테스트, 실습을 독립적으로 수행할 수 있게 한다.
- 강사가 수업에 사용할 진행안·질문·실습 해설을 제공한다.
- 최종 프로젝트에서 여러 패턴을 실제로 조합한다.

## 목표가 아닌 것

- 패턴을 이름과 UML로만 암기시키는 것
- 모든 패턴을 항상 사용해야 하는 규칙으로 제시하는 것
- 러스트의 관용적 단순성을 희생하면서 객체지향 구조를 그대로 복제하는 것
- 첫 단계에서 모든 챕터의 완성 코드를 한 번에 만드는 것

## 실패로 간주할 것

- 패턴 적용 후 코드가 더 복잡해졌는데 이유와 대안이 설명되지 않는 경우
- 독학자는 따라갈 수 없고 강사는 재구성해야 하는 경우
- 챕터 코드가 서로 독립적으로 실행·테스트되지 않는 경우
- 적용 전 코드와 적용 후 코드의 차이를 검증할 수 없는 경우

## 산출물 구조

### Notion

루트 페이지 `디자인 패턴` 아래에 다음 서브 페이지를 만든다.

- `00. 강의 사용법과 러스트 설계 기초`
- `01. 생성 패턴`
- `02. 구조 패턴`
- `03. 행동 패턴`
- `04. 러스트 고유 설계 패턴`
- `05. 동시성·비동기 패턴`
- `06. 실전 프로젝트`
- `부록: 패턴 비교표·용어집·연습문제 해설`

각 분류 페이지 아래에 패턴별 서브 페이지를 만들고, 각 페이지에는 학습 목표, 문제 상황, 적용 전 코드, 문제 분석, 리팩터링 단계, 적용 후 코드, 전후 비교, 러스트 관점, 테스트, 실습, 강사용 메모, 요약을 고정 순서로 둔다.

### 로컬 러스트 코드

`chapters/` 아래에 강의 챕터별 Cargo workspace를 둔다. 각 챕터는 `before/`, `after/`, `tests/`, `exercise/`, `README.md`를 갖는다. 코드는 챕터가 진행될수록 하나의 실전 프로젝트로 연결하되, 각 패턴 예제는 독립적으로 `cargo test`가 가능해야 한다.

## 교육 내용

1. 러스트 설계 기초: 소유권, 빌림, 트레잇, 제네릭, 동적 디스패치, 에러 처리
2. 생성 패턴: Factory Method, Abstract Factory, Builder, Prototype, Singleton의 대안, Object Pool, 의존성 주입, typestate
3. 구조 패턴: Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy, Newtype, Type Erasure, Extension Trait
4. 행동 패턴: Strategy, Observer, Command, State, Template Method, Chain of Responsibility, Iterator, Visitor, Mediator, Memento, Interpreter
5. 러스트 고유 패턴: enum 기반 상태 머신, 타입으로 상태 표현, 함수 조합, interior mutability, RAII, 채널 기반 Actor, 에러 타입 설계, 매크로
6. 동시성·비동기: Send/Sync, Arc/Mutex, 작업 큐, Actor, Future, Stream, backpressure, cancellation
7. 실전: CLI, 이벤트 기반 서버, 플러그인 시스템, 멀티스레드 파이프라인을 단계적으로 구현

## 챕터 공통 템플릿

각 패턴은 다음 순서를 따른다.

1. 학습 목표와 선수 지식
2. 현실적인 요구사항
3. 패턴을 적용하지 않은 최소 구현
4. 변경 요구사항과 초기 구현의 실패
5. 적용할 패턴의 핵심 아이디어
6. 러스트식 리팩터링 과정
7. 최종 구현과 테스트
8. 적용 전/후의 구조·복잡도·성능·확장성 비교
9. 러스트에서 더 단순한 대안이 있는지 검토
10. 사용하면 안 되는 경우와 안티 패턴
11. 연습문제, 확장 과제, 강사용 토론 질문
12. 요약과 복습 퀴즈

## 접근 방법과 결정

### 통합형 교재

본문 안에 독학 설명과 수업 진행 정보를 함께 넣는다. 접근성이 좋지만 장이 길어질 수 있다.

### 본문 + 강사용 가이드

본문은 독학 중심으로 쓰고, 강사용 메모·예상 질문·수업 진행안은 각 페이지의 접힌 섹션 또는 별도 하위 페이지로 둔다. 유지보수 비용은 늘지만 두 사용자를 모두 지원한다.

### 프로젝트 중심 과정

각 단계의 프로젝트에 패턴을 필요에 따라 도입한다. 적용 맥락은 강해지지만 개별 패턴을 빠르게 복습하기는 어렵다.

### 선택한 방향

통합형 본문을 기본으로 하되 강사용 가이드와 프로젝트 중심 진행을 결합한다. 사용자가 독학할 때는 본문과 실습만 따라가고, 강사는 강사용 섹션과 토론 질문을 활용한다. 패턴 설명은 독립 페이지로 유지하고, 프로젝트 페이지에서는 해당 패턴 페이지로 연결한다.

## 제약과 구현 원칙

- 노션의 기존 루트 페이지 `디자인 패턴`을 유지하고 하위 페이지를 추가한다.
- 코드의 기준 언어는 안정 버전 Rust와 Cargo이다.
- 외부 라이브러리는 패턴 설명에 꼭 필요할 때만 사용하고, 핵심 개념은 표준 라이브러리로 먼저 보여준다.
- 적용 전/후 코드는 동일한 요구사항과 테스트로 비교한다.
- 성능 수치는 측정한 경우에만 기재하고, 측정하지 않은 주장은 정성적으로 표시한다.
- 한 번에 전체 완성본을 만들지 않고 기초 챕터부터 검증하면서 확장한다.

## 남은 빌더 결정

- 각 패턴의 최종 코드 예제와 프로젝트 도메인 세부사항
- 챕터별 예상 학습 시간과 난이도
- 벤치마크를 포함할 패턴의 범위
- 노션에서 코드 블록을 본문에 복사할지, 저장소 링크를 중심으로 할지
